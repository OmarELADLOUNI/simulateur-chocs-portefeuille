# Périmètre du dépôt public

Ce dépôt contient uniquement **Portfolio Stress Test** : interface, moteur de calcul, données de configuration, fonctions serveur, construction et documentation du simulateur.

- Ne pas ajouter les pages, textes, illustrations, chapitres ou scripts du site personnel. Leur source est conservée séparément.
- `scripts/integrate-site.mjs` copie seulement le simulateur et ses fonctions vers un site existant. Il ne doit pas importer le site cible dans le dépôt, ni remplacer son accueil, sa configuration ou ses autres rubriques.
- Ne pas versionner les secrets, `.env`, `.netlify`, dépendances ou fichiers générés.
- Toute publication demandée ici se fait en preview Netlify. Une publication de production exige une demande explicite.
- Ne pas ajouter ni exécuter de tests sans demande de l’utilisateur.
