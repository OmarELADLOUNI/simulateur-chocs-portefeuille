# Signaler un problème de sécurité

Pour un problème susceptible d’exposer une clé ou des informations privées, contacter [Omar EL ADLOUNI sur LinkedIn](https://www.linkedin.com/in/omar-el-adlouni/) avant d’en publier les détails dans une issue.

Les clés doivent rester dans `.env` en local et dans les variables d’environnement Netlify pour le serveur. `.env.example` est volontairement vide. Le projet ne nécessite aucun jeton GitHub dans le navigateur.
